# Aniket Gavate — Portfolio

An ultra-minimalist, editorial, and unboxed personal portfolio showcasing full-stack applications, AI agent systems, interactive frontends, and small tools ("side quests").

---

## ✦ Highlights & Design Principles

- **Unboxed & Typographic**: Strictly no card containers, heavy shadows, or boxed wrappers. Content flows naturally using editorial hierarchy and hairline dividers.
- **Grain & Aesthetic**: Subtle SVG film grain overlay on top of deep zinc (`#09090b`) canvas.
- **Straight Typography**: Powered by [Geist Sans](https://vercel.com/font) for reading comfort and [Geist Mono](https://vercel.com/font) for metadata, tags, and navigation.
- **Fast & Zero Dependencies**: 100% Vanilla HTML5, CSS3, and modern JavaScript. Instant load times and 100/100 Lighthouse performance.

## ✦ Sections Included

1. **Header**: Minimalist identity and name.
2. **Projects**: Flagship production systems with real-time category filtering:
   - **AI**: Agentic Chatbot (LangGraph), Quizo AI, AgentGuard (OpenClaw oversight skill).
   - **Fullstack**: Kanso Operations, DigiBoard (real-time canvas), ThreadBox.
   - **Frontend**: Remembr, Blitzz Reader, UDCPR Visual Guide, Architecture Firm Landing, Wrizer Notes (Desktop).
   - **Backend**: Oshi Chat (Socket.io).
3. **Side Quests**: Distinct section for weekend experiments and lightweight tools:
   - **CipherCraft**: Interactive cryptographic cipher playground.
   - **Pixel Cutter**: Zero-upload client-side canvas carousel splitter.
   - **markd**: Web excerpt highlighter Chrome extension.
4. **Experience**: Chronological timeline of freelance and software design experience.
5. **Tools & Technologies**: Categorized technical stack breakdown (Languages, Frontend, Backend & DB, AI & Workflows, Cloud & Dev Tools).
6. **Connect**: Direct links to Resume PDF, GitHub, LinkedIn, X / Twitter, Email, LeetCode, and Medium.

## ✦ Local Development

Simply open `index.html` in any modern browser, or run a local lightweight server:

```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```
